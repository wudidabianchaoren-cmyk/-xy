# 造境手记 · 吴翔宇作品集源码

这是作品集的源码和已编译网页模块备份。**不是已经独立上线的网站，也不包含全部影片、模型和 UE 工程。**

目前保留 Three.js 首页和 UE 实时工作台、神话海湾。现有 UE 串流实现依赖运行 UE 的主机，大型素材也需要独立托管。另在独立副本中测试 UE 5.8 的浏览器 WebGPU 方案；尚未完成本工程的画质和完整交互验证，不能将测试项目管理页当作上线网址。

Cloudflare Pages 可承载前端及受限转发函数，不能运行 UE 编辑器。影片、模型与源照片不通过这个代码仓库保存，不能将源码备份当作全素材备份。

发布设置和现存阻塞见 [Cloudflare 发布说明](DEPLOY-CLOUDFLARE.md)。用户可继续修改代码并推送；Pages Git 集成会部署新提交。只有仓库协作者能修改仓库，网站访客不会因此获得编辑权限。

V32.173 保留原场景，调整了控制文件的后台读写、桌面渲染调度、电视原片比例和碟片切换时序；神话保留原地左右各 15° 环顾，导航索引准备不再阻塞操作入口。11 张氛围图继续使用统一 16:9 展示窗口。本地局部检查不等于公网部署或所有设备上的流畅保证。

本地网页准备脚本 `node scripts/build-pages.mjs --prepare-only` 仅生成 `public` 目录；正式构建默认阻止在后端未完成时发布。原艺术构建脚本使用本机缓存，仅用于本地开发，不作为 Cloudflare 构建命令。
